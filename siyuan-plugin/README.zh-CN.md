# PastePaw 便签同步插件

从自己的 WebDAV 手动拉取 PastePaw 全部便签到指定思源文档。面向 Windows 和安卓，源码按思源官方插件接口实现；真实设备与实际服务器仍需安装后验证。

## 安装与配置

1. 在 PastePaw 的“WebDAV 同步”页填写连接信息，保存并解锁，测试连接通过后完成一次同步。
2. 将本插件发布包中的文件放入思源工作空间 `data/plugins/pastepaw-webdav-sync/`，在集市“已下载”页启用。安卓可通过思源的工作空间同步分发插件文件，再在手机端启用；具体文件访问方式取决于安卓版本及工作空间位置。
3. 点击顶部插件按钮（手机端在插件菜单中），填写目标文档 ID 或 `siyuan://blocks/文档ID` 链接。
4. 给此设备配置能读取同一 `专用目录/v1/notes.json` 的 WebDAV 账号，设置至少 6 个字符的独立解锁密码。推荐服务端只读权限。
5. 点击“立即拉取便签”。后续导入根据文档内的来源 UUID 更新已有内容。

配置思源连接前，请暂停 PastePaw 的剪切板采集或退出 PastePaw，避免从其他软件复制凭据时进入剪切板历史。

## 凭据存储

每台设备的随机标识保存在浏览器本地存储，仅用于区分配置文件，不包含地址或账号。密文位于：

`思源工作空间/data/storage/petal/pastepaw-webdav-sync/webdav-设备标识.vault.json`

地址、目录、用户名和密码一起使用 PBKDF2-SHA256（600000 次）与 AES-256-GCM 加密。解锁密码至少 6 个字符且不保存，解锁后凭据仅在当前插件会话中使用。已有凭据文件仍可使用原密码解锁；要更换密码，请重新配置并保存凭据。默认有效期 30 分钟；锁定、卸载插件或关闭思源后需重新解锁。JavaScript 运行时不能保证所有字符串内存可被立即擦除；本插件不会持久化解锁密码或记录网络参数。

密文可能随思源同步及备份复制。清除当前文件不等于清除备份，离职时应同时撤销服务端对应设备的凭据。忘记解锁密码后只能重新配置。

## 导入规则与限制

- 每条便签使用独立超级块，来源空间 ID、便签 UUID、来源版本和内容基线记录在块属性中。普通文档内容不会被整体覆盖。
- 本插件只发出 WebDAV GET 请求，不上传剪切板，也不把思源修改反向写回 WebDAV。
- 重复拉取相同版本跳过；源便签更新时，只有内容仍匹配导入基线的区域才会更新。
- 手动修改、重复来源标记和未完成的导入区域会保留并报告冲突。可将需要保留的内容移到普通区域后，删除对应插件区域再导入。
- 源便签删除时保留正文，添加“来源便签已删除”标记。
- 同一文档请在一端完成导入并等待思源跨端同步后，再从另一端导入。两端离线同时导入无法保证只产生一个副本；发现重复标记后插件会停止更新该条，交由用户处理。
- 富文本会转换为 Markdown；便签背景颜色保留在 PastePaw，思源文档不复制便签卡片背景。
- 使用思源内核 JSON 网络代理，关闭重定向。支持 HTTP 和 HTTPS；HTTP 会明文传输 WebDAV 凭据和便签内容，HTTPS 需要有效证书。本地凭据文件均加密保存。现代思源可能限制代理访问私网地址，本插件不会绕过这些限制。
- 单次便签索引上限 32 MiB。未知格式、坏 JSON、超大响应和无效记录在写文档前拒绝。

## 构建与测试

插件 0.2.0 支持版本 1/2 的便签索引，并从 `v1/note-assets/` 拉取图片和附件。资源校验通过并保存到思源工作空间后才写入该条正文，支持同次拉取内去重。单个附件不超过 20 MiB，要求思源 3.8.6 或更新版本。其他同步电脑需升级 PastePaw 至 1.5.0，避免旧版本覆盖附件索引。

在 PastePaw 项目根目录执行：

```text
pnpm build:siyuan
pnpm test:siyuan
```

`siyuan-plugin/dist/` 仅包含插件代码、元数据和文档，不包含运行时配置及凭据文件。当前为本地安装插件，尚未发布到思源集市。
