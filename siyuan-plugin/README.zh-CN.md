# PastePaw 便签同步插件

通过自己的 WebDAV 手动同步 PastePaw 便签与指定思源文档，默认单向拉取，可选择双向回传。面向 Windows 和安卓，源码按思源官方插件接口实现；真实设备、实际 Lute 转换和服务器仍需安装后验证。

## 安装与配置

1. 在 PastePaw 的“WebDAV 同步”页填写连接信息，保存并解锁，测试连接通过后完成一次同步。
2. 将本插件发布包中的文件放入思源工作空间 `data/plugins/pastepaw-webdav-sync/`，在集市“已下载”页启用。安卓可通过思源的工作空间同步分发插件文件，再在手机端启用；具体文件访问方式取决于安卓版本及工作空间位置。
3. 点击顶部插件按钮（手机端在插件菜单中），填写目标文档 ID 或 `siyuan://blocks/文档ID` 链接。
4. 给此设备配置能访问同一 `专用目录/v1/notes.json` 的 WebDAV 账号，设置至少 6 个字符的独立解锁密码。默认单向拉取可使用只读账号；开启双向同步需要目录读写权限、PROPFIND 和正确的条件写入支持。
5. 点击“立即拉取便签”，建立每条便签的独立超级块。需要回传时勾选“启用手动双向同步”，点击“立即双向同步”；思源中修改这些区域的标题、正文或待办后，再点击按钮上传。
6. 所有同步电脑升级到 PastePaw 1.6.0，插件升级到 0.3.0。便签索引自动迁移到版本 3；旧客户端会暂停同步，避免覆盖附件和冲突记录。

配置思源连接前，请暂停 PastePaw 的剪切板采集或退出 PastePaw，避免从其他软件复制凭据时进入剪切板历史。

## 凭据存储

每台设备的随机标识保存在浏览器本地存储，仅用于区分配置文件，不包含地址或账号。密文位于：

`思源工作空间/data/storage/petal/pastepaw-webdav-sync/webdav-设备标识.vault.json`

地址、目录、用户名和密码一起使用 PBKDF2-SHA256（600000 次）与 AES-256-GCM 加密。解锁密码至少 6 个字符且不保存，解锁后凭据仅在当前插件会话中使用。已有凭据文件仍可使用原密码解锁；要更换密码，请重新配置并保存凭据。默认有效期 30 分钟；锁定、卸载插件或关闭思源后需重新解锁。JavaScript 运行时不能保证所有字符串内存可被立即擦除；本插件不会持久化解锁密码或记录网络参数。

密文可能随思源同步及备份复制。清除当前文件不等于清除备份，离职时应同时撤销服务端对应设备的凭据。忘记解锁密码后只能重新配置。

每个目标文档的比较基线保存在同目录的 `sync-文档ID.json`，包含便签内容、版本和附件路径，不包含 WebDAV 地址、账号或密码。这是普通笔记数据，会随思源工作空间同步和备份；请按笔记内容的保密要求管理。清除凭据会保留基线和笔记。

## 导入规则与限制

- 每条便签使用独立超级块，来源空间 ID、便签 UUID、来源版本和内容基线记录在块属性中。普通文档内容不会被整体覆盖。
- 默认单向模式只读取 WebDAV。双向模式回传已绑定区域的标题、正文、待办与图片/文件附件；便签的背景、置顶和整体完成状态沿用原值。不上传剪切板，不抓取整篇文档。
- 重复拉取相同版本跳过；源便签更新时，只有内容仍匹配导入基线的区域才会更新。
- 双向模式使用共同基线：单端改动更新另一端，不同字段或不重叠正文自动合并，重叠编辑保留云端主版和思源副本。插件面板可比较并选择保留一版、两版都保留；手动合并先在对应思源区域整理正文，再选择用该区域当前内容合并。决策写入云端后再次点击同步更新思源；其他电脑同步后收到结果。
- 单向模式仍保留手工编辑区域；重复来源标记和未完成导入会停用该条更新。切换双向模式时，历史区域如缺少共同基线会保守保留两版。不要复制超级块的插件标记来创建另一条便签。
- 源便签删除时保留正文，添加“来源便签已删除”标记。
- 删除思源区域仅解除该文档的绑定，不删除云端便签；也可填写超级块 ID 后点击“解除该区域绑定”。普通块填写 ID 后点击“创建为便签”，上传为新便签并在目标文档建立受管理区域，原块保留。
- 同一文档请在一端完成导入并等待思源跨端同步后，再从另一端导入。两端离线同时导入无法保证只产生一个副本；发现重复标记后插件会停止更新该条，交由用户处理。
- 富文本会转换为 Markdown；便签背景颜色保留在 PastePaw，思源文档不复制便签卡片背景。
- 回传支持普通段落、标题、混合嵌套列表/待办、引用、代码、普通表格及图片/附件。图片和附件需独立成段。思源数据库、块引用、公式、嵌入、特殊文字颜色等便签不能表达的内容停止该条回传并保留原文；其他便签继续。插件只管理便签超级块，标题和“创建/更新”信息区域需保持原结构。
- 使用思源内核 JSON 网络代理，关闭重定向。支持 HTTP 和 HTTPS；HTTP 会明文传输 WebDAV 凭据和便签内容，HTTPS 需要有效证书。本地凭据文件均加密保存。现代思源可能限制代理访问私网地址，本插件不会绕过这些限制。
- 单次便签索引上限 32 MiB。未知格式、坏 JSON、超大响应和无效记录在写文档前拒绝。

## 构建与测试

插件 0.3.0 读取版本 1/2/3 的便签索引，双向写入版本 3。附件存于 `v1/note-assets/`，按 SHA256 去重与校验，单个附件不超过 20 MiB；上传计入共享云端总额度（默认 500 MiB），包含备份、剪切板和未引用文件，空间不足保留思源修改，不删除便签腾空间。与电脑共用强 ETag、条件写入和两分钟云端租约；Apache 的暂时弱 ETag 会等待后重读，持续弱标签拒绝双向写入。

本功能是点击按钮的同步与保守合并，不是实时协同编辑。相同文档跨思源设备应先完成工作空间同步，再点击插件按钮；基线缺失或重复标记会保留内容并提示人工处理。

在 PastePaw 项目根目录执行：

```text
pnpm build:siyuan
pnpm test:siyuan
```

`siyuan-plugin/dist/` 仅包含插件代码、元数据和文档，不包含运行时配置及凭据文件。当前为本地安装插件，尚未发布到思源集市。
