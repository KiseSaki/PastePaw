# 便签编辑器

适用于 PastePaw 1.6.0 和思源插件 0.3.0。

- 无序、有序、待办列表可相互嵌套。光标放在要转换的子列表中，再点击对应类型。Tab 缩进最近的列表项，Shift+Tab 提升，空项按回车退出当前层级。
- 粘贴纯文本 Markdown 会转换标题、列表、待办、引用、代码块和表格；富文本粘贴保留原结构。代码块内粘贴保留文字。复制全文或选区为 Markdown，并保留代码语言、缩进、空行和有序列表起始编号。
- Ctrl+F / Ctrl+H 打开当前便签正文查找替换，支持区分大小写、上一处/下一处、逐个或全部替换。替换可以撤销。
- 段落开头输入 `/` 选择插入内容，用上下方向键和回车选择；也可点击“插入”。标题支持 1–6 级。
- 工具栏和选区菜单提供加粗、斜体、下划线、删除线、高亮、行内代码、链接和清除格式。Ctrl+K 编辑链接，可修改显示文字、打开或移除链接。
- 代码块顶部选择语言并复制该块，支持语法高亮。
- 表格内显示行列增删等操作。Excel 复制出的 HTML 表格或用 Tab 分隔的文本可以直接粘贴为可编辑表格。
- 光标所在块可上移、下移、复制、删除；Alt+↑/↓ 移动，Ctrl+Alt+D 复制。拖动块操作栏的手柄可在同一父块内移动。标题与列表可折叠，隐藏内容仍会保存、复制和同步。
- 从“插入”选择图片或附件，也可粘贴截图。附件可另存，SVG/HTML 等文件作为附件保存，不作为图片显示；外部图片地址须先下载后插入。

## 图片与附件

文件以 SHA256 哈希去重，保存在原有 `paste_paw.db` 的 `note_assets` 表中。正文保存稳定的资源标识，不记录电脑上的绝对路径，也不把图片 Base64 塞入正文索引。单个文件上限 20 MiB，本地便签附件总量上限 500 MiB；超过一天且没有便签引用的本地资源会在保存新附件时回收。

WebDAV 将附件保存到专用目录的 `v1/note-assets/<哈希>.bin`，元数据保存在 `notes.json` 中。资源先上传再提交正文；下载和思源导入都检查大小与 SHA256。附件和上一版便签备份均计入设置中的云端总额度，保留备份引用的附件，未引用云端资源至少两分钟后回收。容量不足时停止同步，保留本地正文和文件。

思源插件先下载附件并上传到思源工作空间 `assets/`，再将正文中的资源链接替换为思源链接。同一次拉取内相同附件只上传一次。任一附件校验或保存失败时不导入该条正文；已导入的其他便签保留，修正后重试。该版本要求思源 3.8.6 或更新版本。

## 升级

便签同步格式升级为版本 3。所有参与同步的电脑须升级 PastePaw 至 1.6.0，思源插件须升级至 0.3.0；旧客户端会拒绝新格式，防止覆盖附件与冲突索引。现有数据库及版本 1/2 的便签空间可继续加载，首次同步自动迁移。升级前备份原有数据库、云端目录和加密凭据文件。

自动化覆盖编辑器结构、Markdown、附件完整性、跨设备恢复和思源导入。实际 Windows WebView、安卓思源、个人服务器容量与断网恢复仍需在使用环境中验收。
